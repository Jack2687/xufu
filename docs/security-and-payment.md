# 浏览器、核心流程与调度边界

更新于 2026-10-28。客户页面只调用本平台 `/api/*`。生成结账链接使用按订阅地区匹配的后台代理；付款初始化、US 账单、税费报价、付款提交、只读结果核实使用运行机器默认网络，不向付款进程传递代理凭据，也不占用提链代理租约。

## 输入与公开输出

- Session 仅在服务端内存检查结构、账号一致性及到期时间；此检查不是在线签名验证，响应明确 `online_verified:false`。提链只在独立表加密暂存所需 AT 与空间 ID，结束/取消后清除，不保存整个 Session。
- 卡号及 CVV 在前端提交后清空，在服务端内存及私有 stdin 管道中传给临时付款浏览器；不写数据库、日志、HAR、截图或浏览器存储。订单只保留尾号、当前金额、币种、业务状态与服务费结算状态。
- US 账单资料按订阅邮箱在后台保存并自动读取，不提供公开生成接口，不返回客户订单详情；不随机生成姓名/地址。缺失或重复绑定时在提链/冻结前拦截，旧无账号模版不会复用。原始上游请求、响应、动态令牌及代理密码不进入客户或管理员 API。
- 客户本人输入的 Session、卡资料必然出现在自己的浏览器请求中，不能宣称对此隐藏。保护目标是上游调用过程、平台凭据和其他客户的数据。
- 客户看到横向业务进度；管理员看到业务事件、时间和安全错误分类。管理员可核实付款结果，不能通过管理接口提交他人的银行卡付款。

## 提链与付款状态

提链持久队列使用数据库锁、租约及令牌限制并发并阻止旧进程覆盖结果。无同地区可用代理则排队，不直连，不消耗重试。已知提交前失败可延时重试；上游可能已创建链接但响应不明时转待核实。

付款不把卡资料放入持久队列。全局/每客户并发满时返回 429。每次准备生成唯一 attempt_id，先冻结服务费，再启动隔离浏览器。官方页面完成税费计算后才提供报价；独立提链后的付款需确认同一 attempt、金额和币种，订阅办理则按客户提交时的方案授权自动继续，不增加输入项或中途确认。同账号存在办理中/待核实订阅时禁止另开并行申请。

确认接口先持久化提交标记，再发出单次提交命令。运行时只允许当前结账会话、与客户同意金额相符的确认请求；只读核实模式禁止确认付款。官方页面实时获取自身验证参数，不重放抓包中的付款方式或验证令牌。

成功必须同时满足同一结账会话的 `payment_status=paid`、`status=complete`、`state=succeeded`，存在支付意图时其状态也须成功；金额及币种必须与确认时一致。页面跳转、付款方式创建成功、通知交付进度均不能代替付款成功。

成功状态、服务费账本、余额与冻结金额在同一事务结算，唯一账本引用防止重复结算。提交前失败/取消及明确拒付会解冻；已提交但结果不明保留冻结，不自动重新扣款。进程中断按提交标记恢复为失败或待核实。独立提链模式的额外验证可由客户通过官方页面完成；隐藏链接的订阅办理遇到额外验证会暂停并提示核实，不伪称全自动成功。

## 网络与权限

提链代理测试验证该代理自身出口；没有代理时提链不直连。付款不读取后台代理配置，使用 Chromium 默认网络及运行机器的系统路由。运行时限制请求目标为官方结账所需域名，阻止任意 URL 和非 HTTPS 请求。

仅独立提链工具按需求返回最终链接，链接仅本人/管理员可读，独立加密保存并设有效期。订阅办理的客户及管理员响应都不返回结账链接。客户主动打开链接会进入官方页面，此时该页面的网络调用自然可在客户浏览器查看；普通站内付款的上游请求由服务端完成。

已有保护包括 HttpOnly/SameSite 会话、bcrypt、API key 哈希、逐接口管理员校验、管理 JS 权限校验、同源检查、CSP、参数大小限制、资源 AES-GCM、资金事务、持久限流和审计。API key 不能访问管理员接口。

## 验证边界

Go/PostgreSQL 测试覆盖权限、重复确认、账本结算、取消/崩溃、金额及币种异常、只读恢复；真实 Chromium 对模拟上游测试成功、拒付、结果不明、额外验证等分支。网页抓包验证覆盖模拟付款结果中的信息泄露检查。

已通过默认网络验证真实官方页面初始化和账单税费刷新，未提交真实卡或真实扣款。当前测试不构成真实付款成功证明。额外验证的远程交互没有实现。网页抓包也不能保证拥有服务器/root 权限的人无法查看服务器流量。


## 连续订阅与续费

订阅办理在受理时冻结服务费；卡片只保留于当前内存，排队到期/取消时清除，不能重启后重放付款。付款成功后结算服务费，未选择保留续费则继续续费核实；此时订单保持办理中，直到关闭成功才完成。取消续费最多写一次，未知结果只读重查；查询及取消由服务器默认网络完成。

只有续费任务需要的 AT/空间标识单独加密暂存到 subscription_runs，最长 24 小时且不超过原授权到期时间；保留续费、结束或进入续费待核实时清除。原始响应不进入公开记录。管理员列表/详情字段使用白名单。
