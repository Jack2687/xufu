# 客户订单中心与资金流水

本轮为本地改造，尚未正式发布。订单中心和资金账户延续序付配色，增加业务筛选、分页和手机卡片布局；订单详情仍使用原有七步流程。

## 订单中心

- 搜索订单号或订阅邮箱，可组合付款状态、续费状态、套餐名称和办理状态筛选。“需要关注”包含付款待核实、生效待核实、续费待处理和额外验证。
- 列表展示完整订单号（可复制）、邮箱、来源、套餐与地区、服务费及订单创建时的优惠、服务费冻结/结算/解冻状态、卡尾号、上游报价或确认实收、付款/办理/续费状态、更新时间。
- 付款成功不等同于订阅已生效或续费已关闭。只在有 `charged_amount` 和 `charged_currency` 时标注“已核实实收”；否则标注“含税报价”。JPY 不除以 100，币种大小写均兼容；R 服务费独立展示。
- 筛选范围为最近 200 笔，页面明确标注。公共订单 API 原有 `q` / `status` 查询条件保留；先筛选再取最近 200 笔。

## 资金流水

- 搜索订单号、订阅邮箱、套餐或说明，支持流水类型和日期范围组合筛选。日期按浏览器本地日期计算，包含结束日全天；无效范围有提示。
- 新列 `available_delta` 与 `frozen_delta` 展示可用/冻结各自变化。冻结 80 R 为可用 −80 / 冻结 +80；结算为可用 0 / 冻结 −80；解冻为可用 +80 / 冻结 −80。
- 原 `amount` 的账本含义与所有入账/冻结/结算事务保持不变。本次仅增加读取投影，未迁移或重写历史账本。
- 变动基于同一客户相邻账本余额计算，在截取最近 300 条之前读取前序余额。首条记录按已知资金操作与原订单服务费还原；无法确定的历史冻结显示“未记录”，不伪造 0。
- 显示变动后的可用/冻结余额、订单套餐与服务费优惠、关联订单当前付款金额及卡尾号、说明和时间。关联订单可直接打开详情。“关联订单付款（当前）”明确表示当前付款结果，不冒充流水发生时的支付快照。
- 充值、扣费、累计冻结、解冻/退费汇总跟随筛选；范围限最近 300 条，页面明确说明。累计冻结是区间流量，不是当前冻结余额。每页支持 12/24/48 条。

## 信息与兼容性

客户网页和 API 只得到必要业务字段，不返回账单副本、完整卡号/CVV、AT/Cookie、代理配置、检查点、原始上游错误或订阅结账链接。关联订单同时校验客户归属，历史错误关联也无法越权读取。

OpenAPI 1.6.1 为 `Order` 增加可选 `payment` 摘要，并说明列表 `price_snapshot` 字段范围；原字段和路径保持兼容。不从列表提供重付操作。
